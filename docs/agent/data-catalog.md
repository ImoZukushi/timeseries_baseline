## データセット一覧

### 熱交換器の運転データ（ダミー）

予測モデル・前処理・可視化の動作確認用に、スクリプトで生成した架空のデータです。実在の設備のデータではありません。

| 項目 | 内容 |
|------|------|
| パス | `data/synthetic/train.csv`（学習用）、`data/synthetic/test.csv`（予測対象。目的変数は null）、`data/synthetic/test_answer.csv`（test の正解）、`data/synthetic/crude.csv`（原油A〜Cの性状）、`data/synthetic/chemical.csv`（薬剤の性状）、`data/synthetic/events.csv`（停止・洗浄の記録） |
| 生成方法 | `uv run python scripts/generate_synthetic_heat_exchanger.py`（`--seed` で乱数シード、既定 42。同じシードなら同じデータ） |
| 期間・粒度 | 学習 2019-01-01〜2024-12-31（2,192日）、テスト 2025-01-01〜2025-12-31（365日）の日次。1行 = 1日 |
| 形式 | 横持ち。列は `日付` と、熱交換器10基（`HX01`〜`HX10`）× 9項目（`HX01_汚れ係数` など）の計91列 |
| 目的変数 | `HXnn_汚れ係数` |
| 更新頻度 | 不定期（スクリプトを実行したとき） |
| 機密度 | なし（架空のデータ）。ただし `data/` 以下は git 管理外なので、各自で生成する |
| 注意点 | 停止中の行・欠測・外れ値を含む（下記） |

#### 想定している設備

原油の予熱トレインに並ぶ10基の熱交換器（シェル＆チューブ、対向流）です。

- **低温側（原油）:** HX01 → HX10 の順に直列に流れます。ある機器の低温側出口温度から配管の放熱（0.5〜2℃）を引いた値が、次の機器の低温側入口温度になります。停止中の機器はバイパスされます。
- **温度:** 高温側・低温側の入口・出口温度は、生成の内部で計算しています（汚れの進み方と、原油の温度の受け渡しに使用）。ただし `train.csv` の列には含めていません。
- **高温側（製品油）:** 機器ごとに別の流れで、番号が大きいほど高温です（入口 約180〜315℃）。
- **原油の組成:** 全基で共通です。10〜40日ごとに組成が切り替わり、数日かけて移ります。

#### カラム定義（各機器 `HXnn_` 共通）

| カラム名 | 型 | 単位 | 説明 |
|---------|-----|------|------|
| `日付` | date | － | 日付 |
| `HXnn_汚れ係数` | float | m²·K/kW | **目的変数**。伝熱面の汚れの熱抵抗（約0〜1.6）。洗浄で小さい値に戻る |
| `HXnn_入口圧力` | float | MPa | 低温側の入口圧力 |
| `HXnn_出口圧力` | float | MPa | 低温側の出口圧力（入口との差＝圧力損失は、汚れるほど大きい） |
| `HXnn_高温側流量` | float | t/h | 高温側の流量（停止中は 0） |
| `HXnn_低温側流量` | float | t/h | 低温側（原油）の流量。全基共通の処理量（約300 t/h）に近い（停止中は 0） |
| `HXnn_原油A比率` | float | － | 原油A（軽質、汚れにくい）の比率 |
| `HXnn_原油B比率` | float | － | 原油B（中質）の比率 |
| `HXnn_原油C比率` | float | － | 原油C（重質、汚れやすい）の比率。A + B + C = 1.0（小数3桁） |
| `HXnn_薬剤種類` | categorical | － | 防汚剤: `なし` / `タイプA`（効果大）/ `タイプB`（効果中）。60〜240日ごとに切り替わる |

#### 汚れ係数の生成モデル（正解の構造）

汚れ係数は、1日ごとに「付着 − 除去」で変化します（Ebert-Panchal 型の簡易モデル）。

- **付着:** 原油の組成（C > B > A）・膜温度（高いほど指数的に増える）・低温側流量（少ないほど増える）・薬剤（タイプA 0.55倍、タイプB 0.75倍）・機器ごとの差・日々の揺らぎで決まります。
- **除去:** 低温側流量が多いほど、また汚れ係数が大きいほど大きくなります。
- **温度・圧力への影響（内部）:** 総括伝熱係数は U = 1 / (1/U_clean + 汚れ係数) です。熱交換量は対向流の ε-NTU から計算し、それで出口温度が決まります（温度は出力しません）。
- **圧力損失:** 汚れ係数 1.0 あたり約1.9倍になります。
- **ほかの変数との関係:**
  - その日の圧力損失（`入口圧力 − 出口圧力`）から、汚れ係数を推定できます。
  - 汚れ係数は、過去の運転条件（原油組成・流量・薬剤）の積み重ねで決まります。
  - 温度の影響（高温の機器ほど汚れやすい）は、機器の違い（HX01〜HX10）として現れます。

#### 停止・欠測・外れ値

| 種類 | 内容 | `events.csv` の `種類` |
|------|------|------|
| 洗浄停止 | 汚れ係数が機器ごとの閾値（1.0〜1.6）を超えると、3〜7日止めて洗浄する。洗浄後は小さな値（0.03〜0.08 ＋ 洗浄回数 × 0.01）に戻る | `洗浄停止` |
| 定期修理 | 2021-10-01〜2021-10-21 に全基停止・全基洗浄 | `定期修理（洗浄）` |
| 突発停止 | 機器ごとに年1回程度、1〜3日（洗浄はしない） | `突発停止` |

`events.csv` の `期間` 列は `train` / `test` です。テスト期間の記録（`test`）は正解の情報を含むため、モデルの入力には使わないでください。

- **停止中の行:** 流量は 0 で、圧力・汚れ係数・原油比率は欠測です（薬剤種類は残ります）。
- **センサーの欠測:**
  - 圧力・流量・汚れ係数に、ランダムに約1%。
  - 数日（2〜10日）続く欠測が、機器ごとに年1回程度。
  - 原油比率の欠測（約0.5%）は、3列そろって欠けます。
- **外れ値:** 圧力・流量の約0.2%に、値の跳ね上がり（1.3〜2倍）または急落（0.2〜0.6倍）があります。目的変数（汚れ係数）には入れていません。

#### テスト期間（`test.csv`・`test_answer.csv`）

`test.csv` は、2025-01-01〜2025-12-31 の運転データです。列は `train.csv` と同じで、目的変数 `HXnn_汚れ係数` はすべて null です。

- **続きとして生成:** 学習期間の最後の状態（汚れ係数・洗浄の状況・原油の組成・薬剤の期間・処理量）から続けて生成しています。運転データと汚れ係数は、2024-12-31 から途切れずにつながります。
- **含まれるもの:** 洗浄停止・突発停止・欠測・外れ値も、学習期間と同じ規則で含まれます。2025年に定期修理はありません。
- **正解:** `test_answer.csv` にあります（列 `日付` と `HXnn_汚れ係数`）。予測の評価だけに使い、学習には使わないでください。停止中と欠測の日は null です。
- **`train.csv` の内容:** テスト期間を追加しても、`train.csv` の内容は変わりません。乱数は学習期間から順に使うため、同じシードなら同じファイルになります。

#### 原油の性状（`crude.csv`）

原油A〜Cの性状の表です（3行。同じスクリプトで `train.csv` と一緒に生成されます）。
`原油` 列の値（`A` / `B` / `C`）が、`train.csv` の `HXnn_原油A比率` などの列名に対応します。
日ごとの原油の性状は、比率で重み付けして求められます（例: 硫黄分 = Σ 比率 × 全硫黄分）。

| カラム名 | 型 | 単位 | 説明 |
|---------|-----|------|------|
| `原油` | string | － | 原油の名前（`A` / `B` / `C`） |
| `密度` | float | g/cm³（15℃） | 比重 × 15℃の水の密度（0.99910） |
| `比重` | float | －（15/15℃） | 141.5 / (API比重 + 131.5) |
| `API比重` | float | °API | 大きいほど軽質 |
| `粘度` | float | mm²/s（50℃） | 動粘度 |
| `全硫黄分` | float | 質量% | |
| `金属分` | str | － | 含まれる金属（`バナジウム` / `ニッケル` / `鉄` の1〜3個を `・` で連結） |
| `アスファルテン分` | float | 質量% | 多いほど汚れやすい |
| `炭化水素タイプ` | categorical | － | `パラフィン基` / `混合基` / `ナフテン基` |

| 原油 | 密度 | 比重 | API比重 | 粘度 | 全硫黄分 | 金属分 | アスファルテン分 | 炭化水素タイプ |
|---|---|---|---|---|---|---|---|---|
| A | 0.8341 | 0.8348 | 38.0 | 3.8 | 0.42 | ニッケル | 0.6 | パラフィン基 |
| B | 0.8808 | 0.8816 | 29.0 | 14.5 | 1.85 | バナジウム・ニッケル | 2.8 | 混合基 |
| C | 0.9456 | 0.9465 | 18.0 | 260.0 | 3.30 | バナジウム・ニッケル・鉄 | 9.5 | ナフテン基 |

`train.csv` の汚れやすさとの対応:
- 重質（API比重が小さく、粘度・硫黄分・金属分・アスファルテン分が多い）の原油ほど、汚れ係数が速く増えます（付着の速さの係数 A : B : C = 0.6 : 1.0 : 2.2）。
- この係数は性状から計算した値ではなく、生成モデルで決めた値です。性状は、その順序に合うように設定しています。

#### 薬剤の性状（`chemical.csv`）

防汚剤タイプA・タイプBの性状の表です（2行。同じスクリプトで生成されます）。
`薬剤種類` 列の値は、`train.csv` の `HXnn_薬剤種類` と同じ（`タイプA` / `タイプB`）なので、そのまま結合できます。
`なし` の行はありません。結合すると、薬剤なしの日の性状は欠測になります。

| カラム名 | 型 | 単位 | 説明 |
|---------|-----|------|------|
| `薬剤種類` | string | － | `タイプA` / `タイプB` |
| `有効成分濃度` | float | 質量% | 製品中の有効成分の濃度 |
| `ph` | float | －（25℃） | 水抽出液の pH |
| `比重` | float | －（20/4℃） | |
| `溶解性` | float | g/100g（25℃） | 灯油への溶解度（大きいほど油によく溶ける） |

| 薬剤種類 | 有効成分濃度 | ph | 比重 | 溶解性 |
|---|---|---|---|---|
| タイプA | 45.0 | 7.8 | 0.92 | 35.0 |
| タイプB | 30.0 | 9.2 | 0.98 | 18.0 |

`train.csv` との対応:
- 付着を強く抑える薬剤（タイプA。付着の速さ ×0.55）ほど、有効成分が濃く油によく溶けるように設定しています。タイプB は ×0.75、なしは ×1.0 です。
- 抑制の係数は性状から計算した値ではなく、生成モデルで決めた値です。

#### 読み込み

```python
import polars as pl

from util.csv_io import read_csv_auto
from util.paths import data_dir

df = read_csv_auto(data_dir() / "synthetic" / "train.csv")  # 日付は Datetime 型になる
crude = read_csv_auto(data_dir() / "synthetic" / "crude.csv")
chemical = read_csv_auto(data_dir() / "synthetic" / "chemical.csv")

# 例: HX01 の薬剤の性状を日ごとに付ける（薬剤なしの日は欠測）
hx01 = df.select("日付", pl.col("HX01_薬剤種類").alias("薬剤種類")).join(
    chemical, on="薬剤種類", how="left"
)
```

`薬剤種類` は文字列として読み込まれます。必要に応じて `pl.Categorical` に変換してください。
既存のモデリング基盤（`forecast.series_col` など）で使う場合は、`日付`・`機器`・各項目の縦持ちに変換します。

#### 前処理済みデータセット（`data/processed/dummy/`）

`data/raw/dummy/`（このデータと同じ構成）から `scripts/preprocess_heat_exchanger_dummy.py`
（ノートブック版は `notebook/002_preprocess_heat_exchanger_dummy.ipynb`）で作る、縦持ちのデータセットです。

| ファイル | 行 | 内容 |
|---|---|---|
| `train_dataset.parquet` | 学習期間で `汚れ係数` が欠測でない行（停止日は含まない） | 学習用 |
| `test_dataset.parquet` | テスト期間の全行（停止日を含む。`汚れ係数` は null） | 予測用 |

- 1行 = 1日 × 1機器。キーは `日付` ・ `機器`。両ファイルの列は同じ（40列）。
- クリーニング:
  - 運転中の圧力・流量で、前後15日の中央値から25%以上離れた値を欠測にする（`<列>_外れ値`）。
  - 3日以内の欠測を線形補間する（`<列>_補間` ・ `原油比率_補間`）。停止期間をまたいでは補間しない。
- 洗浄は `events.csv` を使わず、停止期間の日数（4日以上）または停止前後の圧力損失の低下（20%以上）で推定する。
  学習期間の記録とは完全に一致することを確認済み。
- 主な特徴量:
  - `圧力損失` ・ `圧力損失_ma_7`
  - 加重した原油の性状
  - 薬剤の性状（`薬剤有効成分濃度` など）
  - 洗浄サイクル: `洗浄回数`, `洗浄後日数`, `洗浄後運転日数`, `洗浄後累積加重アスファルテン分`,
    `洗浄後薬剤なし日数` ・ `割合`, `洗浄直後圧力損失`, `圧力損失上昇率`
  - `機器番号` ・ `月`
  - 最初の洗浄より前は、洗浄サイクルの特徴量が null。
- 列の一覧と欠測率は `outputs/tables/dummy_hx_prep__dataset_columns.csv` に出力される。
