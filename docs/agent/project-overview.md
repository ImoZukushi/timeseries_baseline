# プロジェクト概要

## 目的

熱交換器10基の日次運転データ（ダミーデータ、`data/raw/dummy/`）から、各機器の**汚れ係数**（伝熱面の汚れの熱抵抗、m²·K/kW）を予測するモデルを作る。

- 学習期間は2019〜2024年（汚れ係数あり）。予測対象はテスト期間の2025年1年分（汚れ係数は null）。
- 予測の流れは、EDA → 前処理（クリーニング・洗浄の推定・特徴量）→ 特徴量の探索 → 学習・チューニング・アンサンブル。
  各段階のスクリプト・ノートブックは [repository-structure.md](repository-structure.md#モデリングの実行手順) を参照。
- データの仕様は [data-catalog.md](data-catalog.md) を参照。

## スコープ外

- 熱交換器のダミーデータ以外のデータセット（列車の運行データ・気象データなど）は扱わない。
- 洗浄の時期の最適化・設備の制御など、予測結果を使った意思決定の仕組みづくりは扱わない。
- 実設備のデータへの適用（ダミーデータは物理的な関係を模して合成したもの）。

## 重要な前提

- テスト期間の運転条件（圧力・流量・原油比率・薬剤）は、1年分がまとめて与えられる。
  前処理の外れ値の判定・補間・洗浄の推定は、その日より後の特徴量（目的変数ではない）を使う。
- テスト期間には停止・洗浄の記録（`events.csv`）が無い。洗浄は、学習期間・テスト期間とも運転データから推定する。
- 評価は、年ごとに「それより前の全期間で学習 → 翌1年で検証」する時系列の交差検証で行う（主指標は RMSE）。
- `data/raw/` は変更しない。生成・加工したデータは `data/synthetic/`・`data/processed/` に書く。
